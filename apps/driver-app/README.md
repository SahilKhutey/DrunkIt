# FACCP Driver Mobile Application

Real-time driver dispatch, GPS location tracking, navigation, and doorstep OTP proof-of-delivery verification app.

## Features

- **Driver Authentication**: Login & state verification.
- **Online/Offline Status**: Toggle dispatch availability.
- **Active Missions**: Assigned order missions, pickup details, and navigation links.
- **Doorstep Verification**: OTP and age proof verification at doorstep handoff.
